**New in 0.1.1:** About & updates opens in Gregario (it did nothing on a tablet without a web browser, such as a Peloton): version, update status and Check now.

**Install:** download `Gregario.apk` below and install it on the tablet (OpenPelo, `adb install -r Gregario.apk`, or
open this page in the tablet's browser). Updating: install the new APK over the old one; your settings stay.

**First ride:** see [First ride](https://github.com/madooroy/Gregario/blob/main/docs/FirstRide.md).
- Peloton Bike+: Grupetto with DirCon and Bike+ ERG on.
- Peloton Bike: Grupetto with DirCon on; Gregario shows the targets to follow with the knob (ERG with a SmartSpin2K).
- Any other Android tablet: a SmartSpin2K on the same Wi-Fi.

Problems: [open an issue](https://github.com/madooroy/Gregario/issues).
